# V.O.I.D. v0.1.0

This is the first Windows desktop preview of V.O.I.D. (Video Offline Index Directory). It keeps the existing browser application while introducing a native desktop runtime with shared UI and product logic.

## Highlights

- Installable Windows desktop application built with Tauri 2.
- Native folder selection and recursive library scanning.
- Persistent SQLite library catalog and disk-backed thumbnail cache.
- Native media streaming without loading complete videos into JavaScript memory.
- Reveal a selected video in Windows Explorer.
- Full SHA-256 verification for duplicate candidates.
- Portable, versioned library metadata backup and restore between web and desktop.
- Existing Explorer, collections, tags, player, playback order, repeat, health, and duplicate-review features remain shared across both editions.

## Downloads

- The `.exe` file is the recommended per-user NSIS installer.
- The `.msi` file is provided for Windows Installer deployments.
- `SHA256SUMS.txt` contains checksums for both installers.

## Important notes

- This preview supports 64-bit Windows 10 and Windows 11.
- The installers are not yet Authenticode-signed, so Windows may display an unknown-publisher warning.
- V.O.I.D. never deletes files in this release. Duplicate review is non-destructive.
- Automatic application updates, filesystem watching, and native FFmpeg thumbnail generation are planned for later releases.

Please report reproducible problems through GitHub Issues with the app version, Windows version, and relevant logs. Do not attach private videos.
