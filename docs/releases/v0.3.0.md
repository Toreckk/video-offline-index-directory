# V.O.I.D. v0.3.0

V.O.I.D. v0.3.0 is in development. Release notes will be finalized with the release proposal.

## Planned focus

- Optional native media analysis behind the shared platform boundary.
- Shared video-duration filtering for Explorer and smart collections, with an always-visible library-scaled range selector and precise bounds.
- Clearer exact and probable duplicate evidence.
- Guarded, desktop-only duplicate cleanup through the Windows Recycle Bin.
- Continued compatibility with the shared browser edition and existing metadata backups.

## Important notes

- Public web deployment and automatic desktop updates are not included in this release.
- Permanent deletion is not included; any approved cleanup workflow must use the Windows Recycle Bin.
