# V.O.I.D. v0.3.0

V.O.I.D. v0.3.0 is in development. Release notes will be finalized with the release proposal.

## Highlights

- Filter Explorer or a smart collection to a precise inclusive video-duration range. The dual-handle control scales from the shortest to longest measured video, stays synchronized with minute inputs, and starts at the complete library span.
- Review exact byte-for-byte copies separately from probable matches. Each group explains its filename, size, duration, dimensions, codec, sampled-content, or complete-hash evidence.
- On Windows desktop, choose the copy to keep and move selected exact redundant copies to the Recycle Bin. V.O.I.D. re-hashes every file immediately before the move, merges supported metadata, protects the keeper, and reports moved, skipped, and failed files.
- Optionally enrich and cache duration, dimensions, and audio/video codecs when `ffprobe` is available on the system. Thumbnail generation and playback continue normally when it is absent.

## Downloads and compatibility

- Windows 10 or Windows 11, x86-64.
- NSIS `.exe` and MSI installers plus `SHA256SUMS.txt` will be attached to the GitHub Release.
- Existing v0.1/v0.2 libraries, cached thumbnails, and portable metadata backups remain supported.

## Important notes

- Public web deployment and automatic desktop updates are not included in this release.
- Permanent deletion is not included. Cleanup is offered only to complete-hash matches in the Windows desktop app and uses the Recycle Bin; probable matches and the browser edition remain non-destructive.
- The installers are unsigned, so Windows may show an unknown-publisher or SmartScreen warning. Verify the downloaded installer against `SHA256SUMS.txt`.
- FFmpeg/ffprobe is not bundled. The optional adapter uses a system installation or development override; its absence is reported in Library Health and does not block the app.
- Automatic updates remain disabled until the signing, key-recovery, tamper, and rollback gates in `docs/UPDATE_SIGNING_ARCHITECTURE.md` are proven.
