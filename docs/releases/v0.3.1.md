# V.O.I.D. v0.3.1

V.O.I.D. v0.3.1 is a compatible polish release focused on clearer smart-collection construction, faster range-control resets, and desktop-shell reliability.

## Highlights

- Find nested-group creation in a prominent dedicated action instead of among ordinary rule buttons.
- Select several existing rules and wrap them into a new All/Any group, or move one rule to another group without recreating it.
- Reset duration minimum and maximum fields directly to the measured library limits with quiet Min/Max actions.
- See accurate Library Source descriptions for retained browser handles, session-only browser access, and persistent desktop access.
- Keep exactly one title bar visible during development remounts, startup, and preference changes—without native/themed overlap or a missing custom bar.
- Preserve comfortable spacing between the themed title bar and both the maximized player and docked tagging workspace, without reducing true fullscreen space.

## Downloads and compatibility

- Windows 10 or Windows 11, x86-64.
- NSIS `.exe` and MSI installers plus `SHA256SUMS.txt` will be attached to the GitHub Release.
- Existing v0.1–v0.3 libraries, collections, cached thumbnails, and portable metadata backups remain supported; no collection migration is required.

## Important notes

- Public web deployment and automatic desktop updates are not included in this release.
- Collection matching semantics are unchanged. The new controls reorganize the existing persisted rule tree.
- Desktop cleanup remains limited to explicitly selected, complete-hash duplicate copies and uses the Windows Recycle Bin.
- The installers remain unsigned, so Windows may show an unknown-publisher or SmartScreen warning. Verify downloads against `SHA256SUMS.txt`.
- FFmpeg/ffprobe remains optional and is not bundled.
