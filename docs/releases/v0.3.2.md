# VOID v0.3.2

VOID v0.3.2 is a compatible performance and naming patch for large libraries and smart collections.

## Highlights

- Reuse loaded thumbnail resources when moving between Explorer and Collections instead of rereading and decoding the same cached JPEG for every mounted tile.
- Open collections with thousands of matches through the same bounded virtualized grid used by Explorer.
- Keep active thumbnail images safe while limiting unused in-memory object URLs and invalidating replaced or cleared cache entries.
- See one consistent `VOID` product name across the browser title, desktop title bar, Windows application metadata, installers, documentation, and GitHub Release.

## Downloads and compatibility

- Windows 10 or Windows 11, x86-64.
- `VOID_0.3.2_x64-setup.exe` and `VOID_0.3.2_x64_en-US.msi` installers plus `SHA256SUMS.txt` will be attached to the GitHub Release.
- Existing v0.1–v0.3.1 libraries, collections, cached thumbnails, and portable metadata backups remain supported; no metadata migration is required.
- Installing the v0.3.2 NSIS package over an earlier NSIS installation, or the v0.3.2 MSI over an earlier MSI, replaces the existing application while preserving VOID's local application data.
- Keep using the same installer type for an in-place upgrade. To switch between NSIS and MSI, uninstall the old package without selecting deletion of app data, then install the other package type.
- The stable package scope, storage keys, desktop application identifier, and repository location remain unchanged.

## Important notes

- Existing published releases and their legacy-named installer assets remain unchanged because release tags and assets are immutable.
- The NSIS upgrade path was manually verified. The MSI was built with normal WiX validation and a pinned upgrade identity, but its runtime upgrade smoke test was explicitly waived for this release.
- Public web deployment and automatic desktop updates are not included in this release.
- Thumbnail generation behavior is unchanged; this release optimizes reuse and rendering after thumbnails exist.
- Desktop cleanup remains limited to explicitly selected, complete-hash duplicate copies and uses the Windows Recycle Bin.
- The installers remain unsigned, so Windows may show an unknown-publisher or SmartScreen warning. Verify downloads against `SHA256SUMS.txt`.
- FFmpeg/ffprobe remains optional and is not bundled.
