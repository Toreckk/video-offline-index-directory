# V.O.I.D. v0.2.0

V.O.I.D. v0.2.0 focuses on Windows desktop hardening and performance for continuously changing, multi-thousand-video libraries while preserving the shared browser edition.

## Planned highlights

- Shared media-index and scanner pipeline boundaries.
- Incremental native library reconciliation for added, changed, renamed, and removed videos.
- VOID-themed Windows title bar with accessible controls and a native-title-bar fallback in Settings.
- Measured performance improvements and documented virtualization and native-thumbnail decisions.
- Continued compatibility with v0.1.0 metadata backups and desktop catalogs.

## Downloads

- The `.exe` file is the recommended per-user NSIS installer.
- The `.msi` file is provided for Windows Installer deployments.
- `SHA256SUMS.txt` contains checksums for both installers.

## Important notes

- This release supports 64-bit Windows 10 and Windows 11.
- Installers remain unsigned and Windows may display an unknown-publisher warning.
- V.O.I.D. does not delete video files.
- Public web deployment and automatic desktop updates are not included in this release.
