# VOID v0.2.0

VOID v0.2.0 focuses on Windows desktop hardening and performance for continuously changing, multi-thousand-video libraries while preserving the shared browser edition.

## Highlights

- Explorer now updates when desktop library files are added, changed, renamed, or removed, without requiring a full manual rescan.
- Rename reconciliation carries tags, favorites, and playback history to the renamed video while transactional catalog updates preserve the last valid index.
- Rename migration removes stale metadata from the previous path, and interrupted watcher thumbnail jobs are safely replaced during rapid filesystem changes.
- Explorer virtualizes large grids, avoiding the cost of mounting thousands of interactive tiles while retaining the complete filtered playback queue.
- Thumbnail work uses a lower-overhead visible-first queue with fewer forced paint delays, improving large initial imports without increasing decoder concurrency.
- A VOID-themed Windows title bar provides accessible window controls, with a persisted native-title-bar fallback in Settings.
- Trusted desktop libraries reconnect explicitly on launch or manual reconnect, including when automatic library restoration is disabled.
- Shared media-index, discovery, and thumbnail-enrichment boundaries keep browser and desktop behavior aligned while allowing native capabilities to evolve independently.
- Continued compatibility with v0.1.0 metadata backups and desktop catalogs.

The committed performance harness covers 2,500- and 5,000-video libraries with 300 tags. Native discovery, catalog persistence, reconciliation, filtering, and virtualized rendering results are recorded in the [v0.2.0 performance report](https://github.com/Toreckk/video-offline-index-directory/blob/v0.2.0/docs/performance/v0.2.md).

## Downloads

- The `.exe` file is the recommended per-user NSIS installer.
- The `.msi` file is provided for Windows Installer deployments.
- `SHA256SUMS.txt` contains checksums for both installers.

## Important notes

- This release supports 64-bit Windows 10 and Windows 11.
- Installers remain unsigned and Windows may display an unknown-publisher warning.
- VOID does not delete video files.
- Public web deployment and automatic desktop updates are not included in this release.
