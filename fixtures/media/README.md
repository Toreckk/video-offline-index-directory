# Synthetic v0.4 media corpus

These two tiny fixtures were generated locally on 2026-09-06 with Edge 152.0.4191.66 Canvas/MediaRecorder: a moving violet rectangle, a short label and a sine tone. No personal footage, third-party media or FFmpeg binaries are included.

Both decoded and played through the actual web application in isolated headless Edge; thumbnails rendered and closing the player stopped playback. The native ffprobe corpus test also passed. These fixtures do not cover 4K, long recordings, every codec or installed WebView2 audio/decoder behavior. Expand the matrix in v0.7.

To generate equivalent fixtures using your installed FFmpeg, run `pwsh -File scripts/generate-media-fixtures.ps1 -Ffmpeg C:\path\to\ffmpeg.exe`. This replaces only the named synthetic outputs. Generated bytes can differ by encoder/version; review them and update hashes if committing replacements. The [candidate test guide](../../docs/V0.4_TESTING.md) explains normal and opt-in native tests.

CI uses a versioned Gyan FFmpeg 9.0.1 test-helper archive, verifies its published SHA-256, and excludes it from distributable installers. [FFmpeg's download page](https://ffmpeg.org/download.html) links that Windows build provider; [Gyan's build page](https://www.gyan.dev/ffmpeg/builds/) documents its GPL build. The helper is optional for VOID users.
